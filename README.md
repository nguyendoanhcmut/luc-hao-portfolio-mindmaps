- **18 / 18 Tác phẩm** hoàn tất 100% cây tri thức tương tác (`_branches.html` và `_branches.md`).

## 3. Kiến Trúc & Tiêu Chuẩn Kỹ Thuật

- **OCR Độ Phân Giải Cao**: Sử dụng pipeline Spec-Driven OCR chuẩn hóa KaTeX, nạp giáp, ngũ hành sinh khắc.
- **Tách Lọc Đồ Hình**: Trích xuất toàn bộ ảnh minh họa quẻ gốc (`assets/*.png`), loại bỏ nhiễu và nhúng trực tiếp vào Markmap.
- **Trình Diễn Taste-Skill**: Thiết kế giao diện cổng tra cứu `index.html` chuẩn taste-skill:
  - Tông màu nền Obsidian Charcoal `#080c14` kết hợp điểm nhấn Lục Ngọc Đế Vương `#10b981` và Hổ Phách Cổ Điển `#f59e0b`.
  - Không hiệu ứng hào quang tím AI slop, không thẻ generic 3 cột.
  - Tích hợp tìm kiếm thời gian thực, bộ lọc chuyên đề, chuyển đổi Lưới Bento / Bảng Ma Trận và bộ xem trước toàn màn hình.

## 4. Hướng Dẫn Sử Dụng

### Mở Trực Tiếp Trên Web
Truy cập [GitHub Pages của dự án](https://nguyendoanhcmut.github.io/luc-hao-portfolio-mindmaps/) để tra cứu tức thì toàn bộ 18 tác phẩm trên máy tính hoặc điện thoại.

### Sử Dụng Cục Bộ (Offline)
1. Tải hoặc sao chép repository:
   ```bash
   git clone https://github.com/nguyendoanhcmut/luc-hao-portfolio-mindmaps.git
   cd luc-hao-portfolio-mindmaps
   ```
2. Mở tệp `index.html` bằng bất kỳ trình duyệt web nào (Chrome, Edge, Firefox, Safari). Toàn bộ mindmap và đồ hình hoạt động độc lập không phụ thuộc kết nối internet ngoài.
